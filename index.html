04 Tuyến buýt so sánh

Ghi nhớ: so sánh hơn

1. Tính từ ngắn (1 âm tiết)

S + be + adj-er + than + …

My street is longer than your street.

2. Tính từ dài (2 âm tiết trở lên)

S + be + more + adj + than + …

The city is more crowded than the countryside.

3. Cách thêm -er

Thường: thêm -erold → older, cheap → cheaper
Tận cùng e: thêm -rlarge → larger, nice → nicer
1 nguyên âm + 1 phụ âm: gấp đôi phụ âmbig → bigger, hot → hotter
Tận cùng y: đổi thành -iernoisy → noisier, busy → busier
Đặc biệtgood → better, bad → worse, far → farther / further
Hay dùng -er dù có 2 âm tiếtquiet → quieter, narrow → narrower

4. Lỗi hay gặp

✗ more bigger → ✓ bigger   ✗ beautifuler → ✓ more beautiful

✗ bigger then → ✓ bigger than
